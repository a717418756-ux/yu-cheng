## 核對成果與限制

- 題庫總數5,647題、法條紀錄4,668筆；兩科合計1,732題。
- 警察升官等本考試題共500題（105/107/109/111/113年，警察法規＋行政法各50題）；另1,232題是延伸考試。
- 已以考選部五年度 **當年最終答案清冊** 比對500/500，題庫字母答案全部吻合。官方複數給分有3題：109年行政法28題(B/D/BD)、111年警察法規2題(A/B)、113年行政法15題(B/D)。
- **不等於法條現行法答案已逐題驗證**。未逐題對現行條文及釋憲效力確認，不能保證現行法命中/正確率90%。
- 本次對45部法律法規做時間字面抽取；823筆主法、1030筆延伸法，共1853筆候選，包括刑度及修業年限等，不可混成救濟期間。
- 284題是「題目或選項含明顯時間字面」的文字自動篩選結果，另有其他未明示時間的相關考題。
- 132種考古題引用法源中，92種未抽到候選時間句，包含多種釋字、專項命令與不含法定期間的基本法；不應誤報成92個已證實的遺漏法條。
- 原始題庫JSON絕未修改。本包為Claude逐筆覆核的工作材料，待確認欄位保持待辦。

## 關鍵漏點示例

- 訴願法§57補送30日 vs §62補正20日；§58「應儘速答辯」，不是固定20日。
- 行政訴訟法§107法院「定期間補正」、§108行政機關接通知10日送卷；不要混淆。
- 國家賠償法施行細則§14補正至少7日、§21協議期日5日前通知、§27協議成立後10日送達。
- 警察人員人事條例**§30-1**先予復職2個月決定、得延長2個月、通知達到後30日內復職；條號不可記成§30。
- 社維法§32：3個月未執行、3個月未移送、6個月未執行，應分開記法律效果。
- 緊急性及偶發性集會許可條文應結合釋字718宣告效力，不得只背原文字面。
