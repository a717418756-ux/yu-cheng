## 一之一、記憶庫・考古題排名・考試英文重點（v4.23.0）

### 🧠 記憶庫（考試區）

六科：**警察法規、憲法與法學緒論、刑法、刑事訴訟法、警察勤務、期限時效（警法＋行政法）**。刑法、刑訴、勤務沿用「升官等記憶樹」的內容；警察法規、憲法依平台法規庫現行條文另行整理；期限時效整合 Claude 時效期間總整理與 GPT 期限時效考古題復核包（2026-11-06）。

| 分頁 | 內容 |
|------|------|
| 🌳 法條樹 | 依體系層層展開（必考／易錯／口訣／新法標籤）。**法條標籤點下去直接開資料庫條文**；🔥N＝警大二技 105–115 年考過幾題。「🙈 挖空回想」把說明遮起來，點一下才顯示 |
| 📝 篇章練習 | 讀完一章就練那一章：題庫的考古題依「關聯法條」對到法條樹各章（沒有關聯法條的觀念題、學理題不硬對篇章，一律歸在最後的「其他」）。每章顯示考古題數、已做、待加強（答錯後還沒再答對），可練全部、只練「沒做過＋錯題」、或練本章猜題（臨時題，不存題庫）。一題可能屬於好幾章；對不到的列在「其他」 |
| 📊 對照表 | 易混淆制度並排比較（如職權法 vs 行政執行法的即時強制、覆議 vs 不信任案） |
| ⚠️ 易錯爭點 | 「✗ 錯誤說法／✓ 正確」整理，加上樹裡所有易錯、必考節點 |
| 🔢 數字口訣 | 多款項目口訣（字首、諧音、邏輯順序，附記憶理由）＋數字速記；「🔢 數字隨機抽考」出四選一 |
| 🃏 閃卡 | 翻面自測，連續答對 2 次算熟，可只看未熟；進度存在設定裡，會隨備份 |
| 🆕 修法 | 修法與憲法判決時間軸 |
| 📋 期限總表 | 只有「期限時效」科目：GPT 從 45 部法規抽出的 1,853 筆期限原句（含優先 432 筆、同數字反查、132 種法源查漏），可依科別／類型／法規／關鍵字篩選，每筆附考古題「▶ 練習」與全國法規連結。這是 GPT 工作底稿，含刑度、修業年限等非救濟期間 |
| 📝 考古對照 | 只有「期限時效」科目：284 題時間考古題、341 題修法提醒題、升官等 105–113 年 500 題官答比對（3 題複數給分），題目依題庫 id 直接出題；題庫裡沒有的題目會顯示「題庫無此」 |

上方搜尋框跨六科搜尋（如「管束」「§88-1」）。

### 📈 考古題排名（考試區，原「猜題庫」）

資料來自雲端「警大二技預測資料包」（105–115 年 2,220 題）。v4.33.0 起移除「🎲 猜題庫」（116 猜題、變化題）與「🧭 二類方向」——猜題無法確認正確性，改以考古題為主；只保留依歷屆考古題統計的排名與練習。以前匯入題庫的猜題（帶「猜題」標籤）可在設定「資料維護 → 移除題庫裡的猜題」一鍵刪除（連同作答紀錄，刪除前存快照）。

- **⚖ 法條**：依考過題數（或近 3 年）排名，附年度分布；「▶ 押題練習」把前 K 條相關的歷屆題一次出完，可只出答錯過的；「🌳 記憶樹」跳到記憶庫裡引用這一條的位置
- **🎯 回測**：押前 10／20／50 條，過去隔年能蓋到幾成題目（與隨機比較）——排名只是優先順序，不是必考清單
- **📚 法規／🧩 題型／📌 出處・規範・學理名詞**：依科目顯示
- **二技／警佐班切換**：最上排可切「警大二技」或「警佐班（佐二類）」。警佐班只列佐二類的四科（憲法與法學緒論、警察法規、警察勤務、刑法與刑事訴訟法），條文排名來自警佐班 107–115 年考古題；「▶ 練習」對應題庫裡考試別＝警佐班的題目（依年度＋題號）
- **📈 趨勢**：出題風格（多選、否定、數字、案例題比例，全期 vs 近3次）與讀法建議；**🧭 近三年出題理由回測**（每題為何會考：常考條文、首次出題、近3年修法、釋憲／憲判、實務見解、時事議題、作業規定與學理）；**🔁 交互驗證**（只看本考試、兩考試合併、合併＋近3次加權，哪種排名押前 50 條隔年蓋得最多）；最近兩年才首次出現的條文（回測顯示單看新考點預測力不高，只當補充）、警佐班考得最多的條文

### 📘 考試英文重點（成長區・英語學習庫）

題型比重（115 年警察專業複選題大增）、**高頻字彙**（240 題字彙題的正確答案＋原句＋干擾字）、**警察專業英文**（依 115 年出題主題分 10 組）、**閱讀・克漏字一鍵轉成英語教材**（用逐句朗讀跟讀）。字彙可 🔊 朗讀、＋單字本。

> 記憶庫的數字抽考、英文抽考都是**臨時題**（id 以 `virt:` 開頭）：借用測驗畫面，不寫入題庫、不留作答紀錄。

## 二、測驗系統

### 四個入口

| 入口 | 出題範圍 |
|------|---------|
| **今日複習** | 有正確答案的選擇題中，遺忘曲線到期的題目（首頁「待複習」、科目選單的「到期 N」用同一判斷：`db.js` `isReviewDue`） |
| **加強複習** | 危險題 ∪ 收藏題（去重） |
| **申論練習** | 申論題（type = es） |
| **數字魔鬼** | 數字記憶訓練 |

**限時模擬考**（首頁「⏱️ 限時模擬考」）：可選**整份考古題**（考試別／年度／科目，照原題號順序）或**隨機抽題**；作答時不顯示對錯，可按「下一題」略過不答，時間到自動交卷。計分可選：**倒扣**（警大二技、警佐班：單選答錯倒扣 1/3 題分；多選每個選項獨立計分、答錯一個選項扣 2/5 題分、扣到該題 0 分；未作答不計分。單選、多選並存時題分比 2：3。依 115 年警佐班簡章文字推算，正式以當年簡章為準）或**不倒扣**（升官等）。交卷後的成績單有分數、答對／答錯／未答、倒扣失分、各科得分與逐題狀況；「📋 檢討錯題與未答」直接看答案解析並標出當時選的答案。最近 30 次成績存在設定 `mock_history`（隨備份）。

**備考教練（`js/coach.js`）**：① **考前衝刺**（考試區「🎯 考前衝刺」）把錯兩次以上、目前仍是錯題、標了錯因、答對但標「猜對的」、收藏、申論自評未掌握的題目收成一份，可勾類別、選科目，並列出最常考的法規。② **信心標記與申論自評**：選擇題答對後可點「🎲 猜對的」（`attempts.confidence='guess'`、題目 `guessed`，下次作答自動清除）；申論看完參考答案後自評掌握／部分／不會（`attempts.selfScore`、題目 `esSelf`），題型列顯示作答時間。③ **本週學習報告**（分析頁最上方）：週一起算，和上週同期比較作答量、正確率、練習天數、申論題數，列出本週答對率最低的三部法規與下週建議。④ **修法提醒**：資料庫法規的修正年度晚於題目出題年度時，作答後顯示提醒，分析頁列出各法規受影響題數（只比年度，僅為提醒，不改官方答案）。⑤ **考試規則**（設定頁）：各考試別的模擬考預設計分（倒扣／不倒扣）存在設定 `exam_rules`，新增別種考試的題目後自動出現。⑥ **備份提醒**：這台裝置超過 7 天沒有備份或還原且作答紀錄達 20 筆時，首頁顯示提醒，可延後 3 天。

**錯因標記**：選擇題答錯後，解析上方出現「這題錯在」：觀念不會／記錯數字或要件／看錯題目／二選一猜錯／粗心，點一下寫入該次作答紀錄（`attempts.wrongReason`）與題目（`wrongWhy`）。分析頁「🧭 錯因分布」統計各類次數、給對策，並可只練某一類錯因的題目。

四個入口都可**多選科目**，選擇會被記住。不限題數，底部「結束」鈕可隨時看統計。

### 遺忘曲線（間隔重複）

```
答對 → 升級，間隔 1 → 3 → 7 → 14 → 30 → 60 → 180 天
答錯 → 降回一半（如 180天 → 14天），隔天重考
```

高等級答錯需**連續答對數次**才會回到長間隔，避免「僥倖答對一次就當熟練」。

### 危險題判定

「最近 3 次全錯」或「錯誤率 > 50% 且答過 2 次以上」（`getWrong`，加強複習用）。
首頁的「危險 N」與數據橫條的危險題是較嚴格的「最近 3 次作答（至少 2 次）全錯」（`db.js` `isDangerQ`），點下去只出這些題（v4.40.0）。

### 首頁主要操作（v4.40.0）

倒數下方一顆大按鈕：有沒做完的一回 → **繼續練習**（直接從下一題接著做）；否則有到期題 → **開始今日複習**；都沒有 → 練危險題或加強複習。下方固定 **⏱️ 限時模擬考**、**🔍 法規搜尋**（到資料庫並把游標放進搜尋框）。展開三區時收起。

> **注意**：題庫中未填正確答案的題目，作答時會提示且**不計入複習進度與統計**，不會污染錯題分析。

## 三、答題功能

### 底部按鈕（作答後才出現）

| 按鈕 | 功能 |
|------|------|
| ☆ | 收藏此題 |
| ✏️ | **手寫標註**（開啟後不能捲動，專心畫） |
| 📄 | **文字備註**（與題庫的「備註／詳解」同一欄位，雙向同步） |
| 下一題 → | 進入下一題 |
| 結束 | 隨時結束並看統計 |

### 手寫標註工具列

```
[紅][黃][綠][藍][黑][⊕自訂]  [細][中][粗]
[✎ 手繪] [╱ 直線] [▭ 螢光]
[↶ 復原] [清除] [✓ 完成]
```

- **手繪**：自由塗畫
- **直線**：拖曳時即時預覽，放開定案
- **螢光**：半透明加粗，蓋在文字上仍讀得到字
- **⊕ 自訂**：開啟色票，任何顏色都能選
- **復原**：最多 8 步

筆跡存在該題，**下次做到這題（公布答案後）會自動顯示**。要捲動長題目時，按「✓ 完成」關閉畫筆即可。

### 鍵盤快捷鍵（電腦、平板外接鍵盤）

| 按鍵 | 功能 |
|------|------|
| 1–6 或 A–F | 選第幾個選項（單選題直接作答，複選題切換勾選） |
| Enter | 複選題送出；已作答時到下一題 |
| → | 已作答時到下一題 |

打字框、備註視窗、手寫標註開啟時不會觸發。

### 不同裝置的版面

- **手機**（寬度 600 以下，如 S23+ 直放 384）：內容最寬 520px。
- **手機橫放**（高度 500 以下，如 S23+ 橫放約 832×340）：填滿全寬，做題畫面壓縮上下留白，維持手機字級。
- **平板**（600–899，如 Tab S8+ 直放 800）：填滿全寬，做題字級放大。
- **電腦／平板橫放**（900 以上，如 Tab S8+ 橫放 1280）：內容欄 900px 置中，底部導覽列與內容欄同寬（v4.38.0 起以底部導覽列取代右下角圓形選單鈕；v4.39.0 起導覽列跟著區變：首頁未選區時只有「設定」，考試區＝首頁／測驗／題庫／資料庫／更多，休閒區＝首頁／書庫／影音庫／設定，成長區＝首頁／英語／運動／設定）。

### 申論題

作答框可直接打字。按「顯示參考答案」後，以**國考答題紙樣式**呈現：稿紙橫線、段落自動編號。下方顯示**關鍵概念檢測**（命中數 + 綠/紅標籤）。

> 參考答案用**換行**分段。在題庫填答案時用「一、」「(一)」開頭再換行，就會呈現標準申論架構。

## 四、新增題目

### 大量新增（推薦）

1. 填科目、年度、考試別（科目、考試別都可自訂：點欄位會列出題庫已有的名稱與題數，打字篩選；沒有的直接輸入就是新的一類）
2. 貼上題目文字
3. 可選填答案列：`1.D 2.A 3.C`（**要帶題號**，跳號沒關係；不要用純字母 `DACB`）
4. 可選填編／章／節，批次套用整批
5. 按「解析預覽」確認再儲存

**貼題格式：**
```
1. 題幹敘述？
(A)選項一
(B)選項二
(C)選項三
(D)選項四
```

規則：
- 題號 = 行首「數字＋`.`／`、`／空格」
- 選項 = (A)~(H)，同行分行皆可
- 題幹中的 `？：（）《》①②③` 一律保留不截斷
- 圈數字 ①②③ 一律當題目內編號，不會被當選項
- PDF 特殊字型的選項符號會自動辨識

### 逐一新增

填題幹、選項、答案、科目／年度／考試別、**關鍵概念**（高頻錯誤分析靠這個，建議都填）、備註、相關法條。

**題組**（共用大題幹）：勾選後每個小題共用同一段大題幹，靠題組編號綁定。

## 五、法規資料庫

### 類別（可自訂）

內建：法規條文｜行政規則｜SOP｜補充資料｜法律解釋與裁判（後三者可直接上傳圖片）。
v4.37.0 起可自訂類別：新增資料、大量新增、變更類別的選單最後一項「＋ 新增類別…」，輸入名稱即可；自訂類別直接以名稱存在資料的 `category`，篩選列自動列出，顯示比照補充資料（可上傳圖片、【標題】與表格排版）。

### SOP 用文字輸入（v4.34.0）

類別選 SOP 後用文字輸入（可搜尋、隨備份），顯示時自動排成流程圖與表格；表單有「📋 插入範本」「👁 預覽」與格式說明。

| 寫法 | 顯示 |
|---|---|
| `【依據】`、`【流程】`、`【作業內容】`… 單獨一行 | 段落標題 |
| `○ 開始`、`○ 結束` | 起訖（圓角） |
| `◇ 是否有立即危險？`，下一行起 `是：…`、`否：…` | 判斷（六角框）＋並排的分支 |
| `【…流程…】` 段落裡的每一行（或 `□` 開頭） | 步驟方框，步驟間自動畫箭頭；開頭的 `1.` 當編號 |
| `流程 \| 權責人員 \| 作業內容`（連續幾行有 `\|`，第一行是表頭） | 表格；手機寬度下每列變卡片 |
| 其他文字 | 照條文排版 |

只有類別是 SOP、且內容有上述標記時才這樣排；以前上傳的 SOP 圖片照舊顯示。

`【標題】` 有 3 個以上時（SOP 與文字附表，如警械種類、警勤加給表），最上面列「跳到」按鈕，點了捲到該段（v4.40.0）。

### SOP 原檔頁面（v4.41.0，之後的 SOP 一律用這個方式）

PDF 原檔**不理解、不重排、不改字**直接放進 App：

| 部分 | 來源 | 說明 |
|---|---|---|
| 畫面 | PDF 每一頁轉成一張圖（`data/sop/<代碼>/01.png…`，寬 1400、約 0.1–0.2 MB） | 樣式、流程圖、箭頭和原檔完全一樣；點圖放大、雙指縮放 |
| 搜尋 | 程式從 PDF 文字層逐字抽出（資料欄位 `pagesText`） | 可搜尋、可展開「原檔文字」對照；每頁以「〔原檔第 N 頁〕」開頭 |
| 整理版（v4.42.0，預設顯示） | 程式把每頁切開：左邊「流程＋權責人員」轉成 SVG（v4.43.0，`f01-<hash>.svg`；原檔跨頁的 A／B／C 接點直接連線，連續幾頁接成一張），右邊「作業內容」長框與純文字頁逐字抽出接成完整文字，附表用整頁圖；寫在 `content`，圖片行是 `![說明](data/sop/…png)` | 流程圖和作業內容不同列、兩邊都完整；手機上圖寬至少 500px 可左右滑動。上方可切換「📑 流程圖＋作業內容／📄 原檔整頁」 |

流程圖 SVG（v4.43.0，`tools/exam_fixes/sop_svg.py`）：PDF 裡的框、線、箭頭是向量路徑，照座標原樣搬成 `<path>`；每段字照 PDF 的位置、字級放成 `<text>`，並用 `textLength` 壓回原檔寬度（手機沒有標楷體，換字型也不會超框）。不理解、不重畫。顏色只有黑／白／灰，轉成 class 由 App 依主題上色；App 先用 `<img>` 載入，再換成內嵌 SVG（只保留 svg／path／text）讓字可選取、頁內搜尋；載不到時顯示「連上網路後再開一次」。檔名帶內容 hash，因為 SOP 快取看過就不再抓。核對：該頁流程區每個字都必須出現在 SVG 裡，否則中止。掃描檔（沒有文字層）做不出文字版，只能看圖。

跨頁接點（`sop_svg.py` `can_join`／`joined_svg`）：原檔一頁放不下時用圓圈 A／B／C 接到下一頁。上一頁底部和下一頁頂部的圓圈字母一一對得上、上一頁的線頭只接圓圈上緣、下一頁的只接下緣時，把幾頁疊成一張，拿掉成對的圓圈，從原本的線頭畫一條線（直下→橫移→直下）接起來；同時拿掉下一頁頂部重複的「流程」「權責人員」與「(續下頁)」、頁碼。要切掉的範圍裡有其他看得到的東西、或接線橫段會重疊，就不接、照原樣分頁，並寫在 `_匯入核對表.md`。字數核對：流程區每個字都在 SVG 裡，或是上述被拿掉的字。單頁裁圖 `fNN.png` 仍會產生（舊版內容引用），新版不用。

版面放鬆（v4.44.0，`sop_svg.py` `_render`）：原檔字的行距等於字高（有的更小、字疊在一起），手機上很擠。整張圖用同一個公式換算：線條、框、箭頭只往垂直方向拉高 `SY`＝1.25 倍（`y' = Y0 + SY·(y − Y0)`，水平不動、線寬不變），字縮成 `FS`＝0.88 倍、每行中心照同一公式換算（框裡的字以框的中心往內縮，對齊方式不變）。流程、相對位置、連線都不變，只是行距和框邊多出空隙。跨頁接點：指向圓圈的箭頭在圓圈拿掉後會停在線中間，一起拿掉，接線改從箭頭後面那條線的線頭接。舊的 SVG 檔不刪（還沒套用新版內容的手機仍引用舊檔名）。

線條粗細統一（v4.46.0，`sop_svg.py` `_geo`／`_arrow`／`LW`）：原檔的箭頭是「1pt 寬的實心長方形＋三角形」，其他線是 0.75pt 框線，兩種畫法看起來一粗一細。現在流程圖不再用 transform 拉高，而是每個點直接換算座標；所有框線統一成 `LW`＝1pt，箭頭的線身改畫成同樣粗細的框線（起點、箭頭尖照公式換算，三角形大小不變），跨頁接線也用同樣粗細、尖角轉折。拿掉 `non-scaling-stroke`，放大縮小時粗細一起變。整頁模式（`page_svg`，補充資料用）不受影響，照原樣。

整理版的規則（`import_sop_pdf.py` `build_layout`）：只把 PDF 在欄寬處斷開的行接回同一段（遇到「一、」「(一)」「1.」「(1)」開頭才換段），不增刪任何字；`【依據】【流程圖】【作業內容】…` 是 App 加的段落標籤（供「跳到」用），原檔的小標仍照原文保留；頁首、頁碼、「(續下頁)」略去。每頁核對「放進文字＋留在圖裡＋略去」＝該頁全部字數，對不上就中止。版型對不上（不是「流程｜權責人員｜作業內容」）時不產生整理版，只顯示原檔整頁。

流程：把 PDF 放進電腦 `Desktop\Y.C\原始資料庫\作業程序SOP`（檔名「正式名稱_民國日期7碼.pdf」）→ `python tools/exam_fixes/import_sop_pdf.py`（轉圖、抽字、產生 `tools/exam_fixes/sop/_匯入核對表.md`：頁數、每頁字數、沒有文字層的掃描頁）→ `python tools/exam_fixes/add_laws.py`（寫進 `data/exam_fixes.json` 的 `lawNew`，帶 `pages`、`pagesText`）→ 手機設定頁「考古題答案更正 → 檢查」套用。
頁面圖放在獨立快取 `yc-pages-v1`（`sw.js`），看過一次就留在裝置裡，App 更新版本不會清掉；沒看過的頁面離線時會顯示「這一頁還沒下載」。圖片不進備份（備份只帶路徑與文字）。

**桌面掃題匯入（v4.45.0）**：電腦上用桌面掃題（`Desktop\Y.C\桌面掃題`，2026.11.14-1 起）法規資料庫分頁的「📄 匯入 SOP PDF」「📄 匯入補充資料 PDF」，同一套 `import_sop_pdf.py`／`sop_svg.py`（桌面掃題照搬）轉好後直接寫進 `exam_data.json`，再用本機完整還原放進 App，不必推 GitHub。差別是圖包在資料裡：`content` 的圖片行是 `![說明](data:image/svg+xml;base64,…)`，`pages` 是整頁 SVG（掃描或字對不上的頁是灰階 JPG）的 data URI，隨備份與雲端同步走，離線也看得到；補充資料只有原檔整頁（`content`＝逐字文字），原本已是【】＋表格文字的保留文字、只加原檔頁面。App 端：`_SOP_IMG` 圖片行同時認 `data/sop/…` 路徑和 data URI；SVG 照樣先用 `<img>` 再換成內嵌（`fetch` 讀 data URI），整頁 SVG 裡有 `<image>`（掃描、印章）時不內嵌、維持 `<img>`；`sw.js` 只攔 http 請求，data URI 不經過快取。

### 大量新增

填法律名稱、類別、來源，貼上條文：

```
第一編 總則
第一章 法例
第1條 （立法目的）
本法所稱……
第7條之1
```

- 編／章／節會**自動繼承**到後面條文
- 支援中文數字、阿拉伯數字、容忍空格
- **一定要有「第X條」**，否則解析不出來
- 同一部法規重複匯入會問「覆蓋」，安全

### 法條連結

題目的「關聯法條」點下去會**跳出彈窗**（不離開當前畫面）：

| 寫法 | 行為 |
|------|------|
| `警察法第2條` | 直接顯示該條內容 |
| `警察法§2` | 同上（§ 是簡寫，支援 `§2-1`） |
| `警察法` | 列出該法規**所有條文清單**，點任一條展開 |

### 法條 ↔ 考題（雙向）

- 題目的關聯法條 = 手動填的 ＋ **題幹、選項、詳解裡寫到的「○○法第X條」自動偵測**（虛線標籤）
- 法條彈窗、法規頁條文卡會顯示 **「📝 相關考題 N 題・答對率」**，按「▶ 練習」直接出這些題
- 分析頁 **「⚖ 弱點法條」**：相關考題答對率最低的條文排行，點一下就練
- 查無法規時提供「🔎 到全國法規資料庫查詢」

### 搜尋

法規搜尋框支援 `法規名§條號` 精準定位，例如 `警察法§2`、`警察法§2-1`。

## 八、備份

| 方式 | 涵蓋 | 建議頻率 |
|------|------|---------|
| **雲端備份** | 9 項純文字資料 | **每週** |
| **本機備份** | 13 項全部（含實體檔案） | **每月／換機前** |

**雲端包含**：題庫（含手寫標註、複習進度）、法規、答題紀錄、設定、倒數日、使用統計、英語教材、單字本、健康數據。
**雲端不含**：電子書、影音、參考書、教材影音 —— 大型檔案走雲端會失敗。

**雲端壓縮（v4.33.0）**：上傳前把備份內容 gzip 壓縮再轉 base64，字串開頭加 `gz1:`（約剩 4 成，18MB → 約 7MB）。Apps Script 照樣存成一個字串檔，不用重新部署；還原時看開頭，有 `gz1:` 先解壓，舊的未壓縮備份照舊讀。瀏覽器不支援 `CompressionStream` 時改傳未壓縮內容。雲端檔因此不是可直接閱讀的 JSON；要給工具讀的請用本機備份的 `exam_data.json`（未壓縮）。從 Google Drive 下載的雲端備份檔，改名 `exam_data.json` 放進資料夾，也能用「從資料夾還原」讀（v4.34.0）。
**資料夾備份加速（v4.33.0）**：書籍、影音等檔案本體若資料夾裡已有同名、同大小的檔案就不重寫，只更新說明檔。

**本機備份的資料夾結構：**
```
你選的資料夾/
├── exam_data.json    ← 所有純文字資料（題庫、法條、英語教材…）
├── ebooks/           ← 休閒電子書
├── media/            ← 休閒影音
├── refbooks/         ← 學習參考書
└── learnmedia/       ← 學習教材影音
```

> **英語教材是文字，存在 `exam_data.json` 裡**，沒有獨立資料夾。

## 改動時的固定規則

1. **版本號同步** —— `js/db.js` 與 `sw.js` 的 `APP_VERSION` 必須**同時改且一致**，否則快取不會更新。

2. **白名單** —— 各模組是 IIFE，新增給 HTML `onclick` 用的函式**必須加進檔尾的匯出物件**，否則 `not defined`：
   - `quiz.js` → `const Quiz = {...}`
   - `data.js` → `const DataMod = {...}`
   - `app.js` → `const App = {...}`
   - `english.js` → `const English = {...}`

3. **匯出必須排在初始化之前** —— 若把 `Object.assign(window, ...)` 放在立即執行的初始化之後，初始化一旦拋錯就會中斷 IIFE，**整個模組的函式全部變成 not defined**（連鎖失效）。初始化也要包 `try/catch`。

4. **searchBlob 要重建** —— 改了來源欄位就要重組，公式見 `exam_data_spec.md`。題目版與法規版公式不同。

5. **條號比對用 `art2n`** —— `articleNumber` 是「主號×1000＋子號」格式，不可直接與純數字比對。缺漏時要 fallback：`(l.articleNumber || art2n(l.article))`。

6. **備份與還原必須對稱** —— 新增資料表時，`gdriveBackup`／`gdriveRestore`／`localBackup`／`localRestore` **四處都要同步加**，否則還原後資料消失。

7. **一次改動常跨多檔** —— 部署時**全部一起上傳**，只傳部分會出現 HTML 有新按鈕但 JS 沒對應函式的情況。

8. **法規資料庫的表格寫入原則（使用者指定，不可擅改）** —— 圖片／PDF 附表一律轉成文字表格：`【標題】` 單獨一行當段落標題；連續幾行 `甲 | 乙` 是表格（第一行是表頭）；優先用兩欄表（手機上維持表格），三欄以上改依段落拆成兩欄表；長清單用 1.／(1) 分層；逐字核對原文，只調順序不改字。顯示由 `data.js` 的 `_lawContentHtml`／`_sopBody` 與 `base.css` 的 `.sop-t`／`.sop-t2` 負責。
   **不可把表格拿掉、改成純文字或改變表格樣式**，即使 GPT 覆核包、稽核清單或其他工具這樣建議；只加不減的改善（段落跳轉、間距）可以做但要寫明。要改變表格的呈現方式，必須先經使用者確認。範例：`tools/exam_fixes/law_tables_1112.py`。
