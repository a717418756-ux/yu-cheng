## 快速查找：症狀 → 檔案

| 症狀 | 先看這個檔 |
|------|-----------|
| 大量貼題匯入錯亂 | utils.js（parseQuestions） |
| 逐一新增題目存不進去/欄位錯 | data.js（saveQ） |
| 法規匯入或排序錯 | utils.js（art2n）＋ data.js（saveLaw/parseLawText） |
| 答題選項/複習排程異常 | quiz.js |
| 電子書朗讀重複/卡頓/不翻頁 | tts.js |
| 電子書翻頁/顯示異常 | books.js |
| 電子紙模式殘影/耗電/太慢 | eink.css |
| 首頁熱力圖/每日任務顯示異常 | data.js（畫面邏輯）＋ base.css（樣式）＋ dtask.js（任務邏輯） |
| 版本更新後功能沒生效 | db.js／sw.js（先確認版本號有沒有同步改） |
| 高頻錯誤分析沒東西 | stats.js（邏輯）─ 但根源通常是題目沒填 keywords |
| 影音播放異常 | media.js |
| 備份/還原失敗 | settings.js |

## 改動時的固定規則

1. **版本號**：`js/db.js` 和 `sw.js` 兩處的 `APP_VERSION` 要**同步改**，且一致。
2. **data.js 加新函式給 HTML onclick 用**：一定要加進檔尾的 `DataMod` 白名單，否則會 `not defined`。
3. **一次功能改動常跨 2-3 個檔**（例如新增題目欄位可能要動 index.html + data.js + utils.js），部署時**全部一起上傳**。

## 二、題庫 — 新增題目

### 大量新增（推薦，效率最高）

1. 填科目、年度、考試別
2. 貼上題目文字（格式見下）
3. 可選填答案列：`1.D 2.A 3.C`（按題號對應，跳號沒關係；不要用純字母 DACB）
4. 可選填編/章/節，批次套用到整批題目
5. 按「解析預覽」確認無誤再儲存

**貼題文字格式：**
```
1. 題幹敘述？
(A)選項一
(B)選項二
(C)選項三
(D)選項四
```

規則：
- 題號 = 行首「數字＋`.`／`、`／空格」
- 選項 = (A)~(H)，同行分行皆可
- 題幹 = 題號到第一個 (A) 之間全部保留，中間 ？：（）《》①②③ 不截斷
- 圈數字 ①②③ 一律當題目內編號，不會被當選項
- PDF 特殊字型的選項符號會自動辨識轉換

### 逐一新增

填題幹、選項、答案、科目/年度/考試別、關鍵概念（高頻錯誤分析要靠這個，建議都填）、備註、相關法條。

**題組**（共用大題幹的閱讀測驗題）：勾選題組後，每個小題共用同一段大題幹，靠題組編號綁定、可設定組內順序。

## 三、資料庫（法規）— 新增資料

### 四種類別
法規條文 / SOP / 補充資料 / 函釋（後三者可直接上傳圖片，不用打字）

### 大量新增（推薦）

1. 填法律名稱、類別、來源
2. 貼上條文文字（格式見下）

**貼法規文字格式：**
```
第一編 總則
第一章 法例
第1條 （立法目的）
本法所稱……
第2條
內容
第7條之1
```

規則：
- 第N編／第N章／第N節 = 階層，會自動繼承到後面條文，不用每條重寫
- 第N條／第N條之M = 條文開始，之後都是內容
- 支援中文數字、阿拉伯數字，容忍空格
- **一定要有「第X條」，否則解析不出來**

同一部法規重複匯入會問「覆蓋」，安全不會重複。

### 逐一新增

填法律名稱、條號、編/章/節、類別、標題、內容（或上傳圖片）、關鍵概念、相關法條、來源、備註。

## 四、題幹標記語法

新增題目時可用，答題時自動呈現樣式：

| 標記 | 效果 |
|------|------|
| `___` | 填空底線 |
| `[[提示]]` | 填空（含提示） |
| `**文字**` | 畫線強調 |
| `//文字//` | 粗體 |
| `>> 文字` | 段落首行縮排 |

點新增題目標題旁的 ⓘ 可隨時查看。

## 七、設定裡的實用工具

- **重建條號索引**：修正法規排序、補齊題目與法規的搜尋索引。**匯入大量法條後按一次。**

## 八、資料安全

- 所有資料存本機（IndexedDB），不上傳伺服器
- 別清網站資料（會清掉題庫），有雲端備份就不怕
- 匯出的 JSON 可交給程式批次處理，只需改 `questions`／`laws` 陣列，其餘照抄

---

## 九、更新後畫面沒變？

App 有兩層快取：Service Worker（程式管的）與瀏覽器 HTTP 快取（瀏覽器自己管的，程式碰不到）。更新後沒變，通常是第二層還握著舊檔，**完全關閉 App 重開**即可，跟更新功能正不正常無關。
