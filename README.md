## 二、大量匯入題目（重點功能）

貼上整份考題純文字，自動切分。**規則：**

1. **題號**：行首「數字 + `.`／`、`／空格」（如 `7.` `14.` `1、`）。跳號沒關係。
2. **選項**：`(A)(B)(C)(D)(E)` + 敘述。同行或分行都可。
3. **題幹**：題號到第一個 `(A)` 之間全都是題幹，中間 `？：（）《》①②③` 一律**保留不截斷**。
4. **圈數字 ①②③**：一律當「題目內編號」，不會被當選項或題號。
5. **PUA 亂碼**：PDF 特殊字型的選項符號（U+E18C~E191）自動轉 (A)~(F)。

**匯入後務必按「解析預覽」確認再存。** 若某題跑掉，貼那一題原文即可除錯。

## 三、題幹標記語法

在題幹或選項打這些符號，答題時自動呈現樣式：

| 標記 | 效果 |
|------|------|
| `___` | 填空底線 |
| `[[提示]]` | 填空（含提示） |
| `**文字**` | 畫線強調 |
| `//文字//` | 粗體 |
| `>> 文字` | 段落首行縮排 |

（大量新增／逐一新增題目的標題旁，點 ⓘ 可查看。）

## 四、題目欄位重點

- **關鍵概念**（keywords）：**高頻錯誤分析的燃料**，建議每題填。沒填則分析是空的。
- **題組**：共用大題幹的閱讀測驗題，靠 groupId 綁定，每小題獨立作答。
- 科目 / 年度 / 考試別：分類與四層導覽用（年度→考科→考試別→題目）。

## 六、設定裡的實用工具

## 七、維護須知（改程式時）

**版本號**：改程式一定要同步改兩處，且一致：
- `js/db.js`（約 327 行）`APP_VERSION`
- `sw.js`（約 10 行）`APP_VERSION`

**檔案分工**：固定結構 → HTML；動態內容 → JS；樣式 → CSS。一次改動常需同時改 2-3 檔，**全部上傳**才完整。

**data.js 的白名單**：data.js 是 IIFE 包裝，給 HTML `onclick` 用的函式**必須列入檔尾 `DataMod` 白名單**，否則會 `not defined`。

**核心解析器**：`js/utils.js` 的 `parseQuestions` / `preprocessQuestionText`。改動後務必用真實題目回歸測試。

## 八、關於「更新後畫面沒變」

兩層快取：
1. **Service Worker 快取**（程式控制）
2. **瀏覽器 HTTP 快取**（瀏覽器自管，程式碰不到）

更新後若沒變，是第 2 層還握著舊檔。**完全關閉 App 重開**，或用無痕開一次。與更新功能是否正常無關。

---

## 九、資料安全

- 所有資料存本機（IndexedDB），不上傳伺服器。
- **別清網站資料**（會清掉題庫）。有雲端備份就不怕。
- 匯出／匯入 JSON：Python 處理時只動 `questions`、中文用 `ensure_ascii=False`、其餘頂層鍵與 version 照抄。
