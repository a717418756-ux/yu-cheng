## 一之一、記憶庫・猜題庫・考試英文重點（v4.23.0）

### 🧠 記憶庫（考試區）

五科：**警察法規、憲法與法學緒論、刑法、刑事訴訟法、警察勤務**。刑法、刑訴、勤務沿用「升官等記憶樹」的內容；警察法規、憲法依平台法規庫現行條文另行整理。

| 分頁 | 內容 |
|------|------|
| 🌳 法條樹 | 依體系層層展開（必考／易錯／口訣／新法標籤）。**法條標籤點下去直接開資料庫條文**；🔥N＝警大二技 105–115 年考過幾題。「🙈 挖空回想」把說明遮起來，點一下才顯示 |
| 📊 對照表 | 易混淆制度並排比較（如職權法 vs 行政執行法的即時強制、覆議 vs 不信任案） |
| ⚠️ 易錯爭點 | 「✗ 錯誤說法／✓ 正確」整理，加上樹裡所有易錯、必考節點 |
| 🔢 數字口訣 | 多款項目口訣（字首、諧音、邏輯順序，附記憶理由）＋數字速記；「🔢 數字隨機抽考」出四選一 |
| 🃏 閃卡 | 翻面自測，連續答對 2 次算熟，可只看未熟；進度存在設定裡，會隨備份 |
| 🆕 修法 | 修法與憲法判決時間軸 |

上方搜尋框跨五科搜尋（如「管束」「§88-1」）。

### 🎯 猜題庫（考試區）

資料來自雲端「警大二技預測資料包」（105–115 年 2,220 題）。

- **⚖ 法條**：依考過題數（或近 3 年）排名，附年度分布；「▶ 押題練習」把前 K 條相關的歷屆題一次出完，可只出答錯過的；「🌳 記憶樹」跳到記憶庫裡引用這一條的位置
- **🎯 回測**：押前 10／20／50 條，過去隔年能蓋到幾成題目（與隨機比較）——排名只是優先順序，不是必考清單
- **📚 法規／🧩 題型／📌 出處・規範・學理名詞**：依科目顯示
- **二技／警佐班切換**：最上排可切「警大二技」或「警佐班（佐二類）」。警佐班只列佐二類的四科（憲法與法學緒論、警察法規、警察勤務、刑法與刑事訴訟法），條文排名來自警佐班 107–115 年考古題；「▶ 練習」對應題庫裡考試別＝警佐班的題目（依年度＋題號）
- **📈 趨勢**：出題風格（多選、否定、數字、案例題比例，全期 vs 近3次）與讀法建議；**🧭 近三年出題理由回測**（每題為何會考：常考條文、首次出題、近3年修法、釋憲／憲判、實務見解、時事議題、作業規定與學理）；**🔁 交互驗證**（只看本考試、兩考試合併、合併＋近3次加權，哪種排名押前 50 條隔年蓋得最多）；最近兩年才首次出現的條文（回測顯示單看新考點預測力不高，只當補充）、警佐班考得最多的條文
- **🎲 猜題庫**：116 年二技＋警佐班猜題，四科各 **猜題 100＋變化題 100**（共 800 題）。猜題＝沒考過原題但考點樣式類似；變化題＝近三年考古題換角度、數字、對象改寫，與原題不重複（撰寫時以 4 字片段比對全部二技、警佐班考古題，過於相似的已改寫）。每題附詳解、出題理由、母題與法條。可「直接練習」（不存題庫）或「匯入題庫」（考試別「116猜題」「116變化題」）；舊版升官等猜題（「猜題（原題）／猜題（變化題）」）可一鍵刪除

### 📘 考試英文重點（成長區・英語學習庫）

題型比重（115 年警察專業複選題大增）、**高頻字彙**（240 題字彙題的正確答案＋原句＋干擾字）、**警察專業英文**（依 115 年出題主題分 10 組）、**閱讀・克漏字一鍵轉成英語教材**（用逐句朗讀跟讀）。字彙可 🔊 朗讀、＋單字本。

> 記憶庫的數字抽考、英文抽考、猜題「直接練習」都是**臨時題**（id 以 `virt:` 開頭）：借用測驗畫面，不寫入題庫、不留作答紀錄。

## 二、測驗系統

### 四個入口

| 入口 | 出題範圍 |
|------|---------|
| **今日複習** | 選擇題中，遺忘曲線到期的題目 |
| **加強複習** | 危險題 ∪ 收藏題（去重） |
| **申論練習** | 申論題（type = es） |
| **數字魔鬼** | 數字記憶訓練 |

四個入口都可**多選科目**，選擇會被記住。不限題數，底部「結束」鈕可隨時看統計。

### 遺忘曲線（間隔重複）

```
答對 → 升級，間隔 1 → 3 → 7 → 14 → 30 → 60 → 180 天
答錯 → 降回一半（如 180天 → 14天），隔天重考
```

高等級答錯需**連續答對數次**才會回到長間隔，避免「僥倖答對一次就當熟練」。

### 危險題判定

「最近 3 次全錯」或「錯誤率 > 50% 且答過 2 次以上」。

> **注意**：題庫中未填正確答案的題目，作答時會提示且**不計入複習進度與統計**，不會污染錯題分析。

## 三、答題功能

### 底部按鈕（作答後才出現）

| 按鈕 | 功能 |
|------|------|
| ☆ | 收藏此題 |
| ✏️ | **手寫標註**（開啟後不能捲動，專心畫） |
| 📄 | **文字備註**（與題庫的「備註／詳解」同一欄位，雙向同步） |
| 下一題 → | 進入下一題 |
| 結束 | 隨時結束並看統計 |

### 手寫標註工具列

```
[紅][黃][綠][藍][黑][⊕自訂]  [細][中][粗]
[✎ 手繪] [╱ 直線] [▭ 螢光]
[↶ 復原] [清除] [✓ 完成]
```

- **手繪**：自由塗畫
- **直線**：拖曳時即時預覽，放開定案
- **螢光**：半透明加粗，蓋在文字上仍讀得到字
- **⊕ 自訂**：開啟色票，任何顏色都能選
- **復原**：最多 8 步

筆跡存在該題，**下次做到這題（公布答案後）會自動顯示**。要捲動長題目時，按「✓ 完成」關閉畫筆即可。

### 申論題

作答框可直接打字。按「顯示參考答案」後，以**國考答題紙樣式**呈現：稿紙橫線、段落自動編號。下方顯示**關鍵概念檢測**（命中數 + 綠/紅標籤）。

> 參考答案用**換行**分段。在題庫填答案時用「一、」「(一)」開頭再換行，就會呈現標準申論架構。

## 四、新增題目

### 大量新增（推薦）

1. 填科目、年度、考試別
2. 貼上題目文字
3. 可選填答案列：`1.D 2.A 3.C`（**要帶題號**，跳號沒關係；不要用純字母 `DACB`）
4. 可選填編／章／節，批次套用整批
5. 按「解析預覽」確認再儲存

**貼題格式：**
```
1. 題幹敘述？
(A)選項一
(B)選項二
(C)選項三
(D)選項四
```

規則：
- 題號 = 行首「數字＋`.`／`、`／空格」
- 選項 = (A)~(H)，同行分行皆可
- 題幹中的 `？：（）《》①②③` 一律保留不截斷
- 圈數字 ①②③ 一律當題目內編號，不會被當選項
- PDF 特殊字型的選項符號會自動辨識

### 逐一新增

填題幹、選項、答案、科目／年度／考試別、**關鍵概念**（高頻錯誤分析靠這個，建議都填）、備註、相關法條。

**題組**（共用大題幹）：勾選後每個小題共用同一段大題幹，靠題組編號綁定。

## 五、法規資料庫

### 四種類別

法規條文｜SOP｜補充資料｜函釋（後三者可直接上傳圖片）

### 大量新增

填法律名稱、類別、來源，貼上條文：

```
第一編 總則
第一章 法例
第1條 （立法目的）
本法所稱……
第7條之1
```

- 編／章／節會**自動繼承**到後面條文
- 支援中文數字、阿拉伯數字、容忍空格
- **一定要有「第X條」**，否則解析不出來
- 同一部法規重複匯入會問「覆蓋」，安全

### 法條連結

題目的「關聯法條」點下去會**跳出彈窗**（不離開當前畫面）：

| 寫法 | 行為 |
|------|------|
| `警察法第2條` | 直接顯示該條內容 |
| `警察法§2` | 同上（§ 是簡寫，支援 `§2-1`） |
| `警察法` | 列出該法規**所有條文清單**，點任一條展開 |

### 法條 ↔ 考題（雙向）

- 題目的關聯法條 = 手動填的 ＋ **題幹、選項、詳解裡寫到的「○○法第X條」自動偵測**（虛線標籤）
- 法條彈窗、法規頁條文卡會顯示 **「📝 相關考題 N 題・答對率」**，按「▶ 練習」直接出這些題
- 分析頁 **「⚖ 弱點法條」**：相關考題答對率最低的條文排行，點一下就練
- 查無法規時提供「🔎 到全國法規資料庫查詢」

### 搜尋

法規搜尋框支援 `法規名§條號` 精準定位，例如 `警察法§2`、`警察法§2-1`。

## 六、朗讀功能

**書庫**：支援系統語音與 Azure 語音。從當前位置開始，唸完自動翻頁，讀到書末停止。播放中可調語速、切換聲音。

**成長區**：英語教材逐句朗讀，播放中可調語速、點任一句跳讀。

**Azure 用量估算**：設定頁顯示本月字元數與免費額度百分比（達 80% 轉警示色，跨月自動歸零）。

> 這是**估算值**，實際用量以 Azure 後台為準。免費層每月 50 萬字元，朗讀整本電子書約佔 30%。

## 七、返回鍵行為

按返回會**逐層關閉**，不會直接退出：

```
確認框 → FAB → 加號選單 → 電子書閱讀器 → 播放器
→ 彈窗 → 法條檢視 → 英語閱讀器 → 標註模式
→ 答題畫面 → 上一頁 → 首頁 → 離開 App
```

例如：資料庫 → 看法條 → 返回（回資料庫）→ 返回（回首頁）→ 返回（離開）。

## 八、備份

| 方式 | 涵蓋 | 建議頻率 |
|------|------|---------|
| **雲端備份** | 9 項純文字資料 | **每週** |
| **本機備份** | 13 項全部（含實體檔案） | **每月／換機前** |

**雲端包含**：題庫（含手寫標註、複習進度）、法規、答題紀錄、設定、倒數日、使用統計、英語教材、單字本、健康數據。
**雲端不含**：電子書、影音、參考書、教材影音 —— 大型檔案走雲端會失敗。

**本機備份的資料夾結構：**
```
你選的資料夾/
├── exam_data.json    ← 所有純文字資料（題庫、法條、英語教材…）
├── ebooks/           ← 休閒電子書
├── media/            ← 休閒影音
├── refbooks/         ← 學習參考書
└── learnmedia/       ← 學習教材影音
```

> **英語教材是文字，存在 `exam_data.json` 裡**，沒有獨立資料夾。

### 多台裝置防誤蓋（v4.22.38）

| 機制 | 說明 |
|------|------|
| **裝置名稱** | 第一次備份時命名（手機／平板／電腦）。只存在這台，不會被還原覆蓋 |
| **備份資訊** | 每份備份都記錄：備份時間、哪台裝置、題目／法條／作答筆數、最後作答日 |
| **覆蓋前比較** | 備份前先讀**雲端（或資料夾）現有那份**，和這台並排比較。其他裝置在你上次同步後備份過、或對方資料比較多 → 紅色警告 |
| **檢查同步狀態** | 只比較、不變更，直接告訴你該「備份」還是「還原」 |
| **還原前快照** | 每次還原前自動保留這台目前的資料，還原錯了到設定頁按「復原」 |
| **資料夾版本紀錄** | 舊的 `exam_data.json` 移到 `history/`（保留 10 份），還原時可選版本 |
| **雲端版本紀錄** | 換成新版 Apps Script（`docs/gas-backup.gs`）後，雲端自動保留 10 份，還原時可選 |

**建議習慣**：換裝置使用前先按「🔍 檢查同步狀態」；用完那台就「備份到雲端」。

### Apps Script 程式碼

設定頁「說明 ▾」→「📋 複製程式碼」，或直接開 [`docs/gas-backup.gs`](docs/gas-backup.gs)。
貼到 script.google.com、**把第一行密碼改成和 App 一樣**，部署成網路應用程式（執行身分：我／存取權：任何人）。
已在用舊版的：部署 → 管理部署 → 編輯 → 新版本，網址不變。舊版程式碼仍可使用（只是每次比較都要下載整份）。

## 十二、常見狀況

| 狀況 | 解法 |
|------|------|
| 更新後畫面沒變 | App 有兩層快取，**完全關閉再開** |

## 改動時的固定規則

1. **版本號同步** —— `js/db.js` 與 `sw.js` 的 `APP_VERSION` 必須**同時改且一致**，否則快取不會更新。

2. **白名單** —— 各模組是 IIFE，新增給 HTML `onclick` 用的函式**必須加進檔尾的匯出物件**，否則 `not defined`：
   - `quiz.js` → `const Quiz = {...}`
   - `data.js` → `const DataMod = {...}`
   - `app.js` → `const App = {...}`
   - `english.js` → `const English = {...}`

3. **匯出必須排在初始化之前** —— 若把 `Object.assign(window, ...)` 放在立即執行的初始化之後，初始化一旦拋錯就會中斷 IIFE，**整個模組的函式全部變成 not defined**（連鎖失效）。初始化也要包 `try/catch`。

4. **searchBlob 要重建** —— 改了來源欄位就要重組，公式見 `exam_data_spec.md`。題目版與法規版公式不同。

5. **條號比對用 `art2n`** —— `articleNumber` 是「主號×1000＋子號」格式，不可直接與純數字比對。缺漏時要 fallback：`(l.articleNumber || art2n(l.article))`。

6. **備份與還原必須對稱** —— 新增資料表時，`gdriveBackup`／`gdriveRestore`／`localBackup`／`localRestore` **四處都要同步加**，否則還原後資料消失。

7. **一次改動常跨多檔** —— 部署時**全部一起上傳**，只傳部分會出現 HTML 有新按鈕但 JS 沒對應函式的情況。
